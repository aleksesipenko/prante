# PRANTE / ПРАНТЕ

**ПРАНТЕ** — Telegram-first ассистент для письменного переводчика: предпереводческий анализ, глоссарий, контроль терминологии, черновой перевод и адаптивная переводческая память.

Цель MVP: снять с переводчика монотонную подготовительную работу перед переводом — увидеть повторы, термины, риски стиля/читабельности и получить управляемый черновой перевод с учетом собственного глоссария.

## Базовые функции MVP

- Подсчет повторений и частотных фрагментов в исходном тексте.
- Личный/проектный глоссарий: добавление, хранение, редактирование терминов.
- Рекомендации по глоссарию: какие термины стоит добавить и где терминология может быть непоследовательной.
- Оценка сохранения стиля и читабельности перевода.
- Генерация чернового перевода на основе текста, глоссария и выбранных настроек.
- После MVP: сравнение черновика с финальной/одобренной версией и накопление правил перевода.

## Архитектурный принцип

Ядро продукта — не автономный “магический агент”, а управляемый переводческий pipeline:

```text
детерминированные tools + LLM для генерации/объяснения + память с подтверждением пользователя
```

Повторы, глоссарий, fuzzy matching, QA и diff считаются детерминированно. LLM используется для чернового перевода, объяснения правок и предложения правил, но не записывает активную память без подтверждения пользователя.
