# PRANTE / ПРАНТЕ

**ПРАНТЕ** — Telegram-бот для предпереводческого анализа текста письменного переводчика.

Цель MVP: снять с переводчика монотонную подготовительную работу перед переводом: увидеть повторы, термины, стиль, потенциальные риски и получить управляемый черновой перевод с учетом собственного глоссария.

## Базовые функции MVP

- Подсчет повторений и частотных фрагментов в исходном тексте.
- Личный глоссарий пользователя: добавление, хранение, редактирование терминов.
- Рекомендации по глоссарию: какие термины стоит добавить и где терминология может быть непоследовательной.
- Оценка сохранения стиля и читабельности перевода.
- Генерация чернового перевода на основе текста, глоссария и выбранных настроек.
