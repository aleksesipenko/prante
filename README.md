# PRANTE / ПРАНТЕ

**ПРАНТЕ** — Telegram-first ассистент для письменного переводчика: предпереводческий анализ текста, глоссарий, контроль терминологии, черновой перевод и адаптивная переводческая память.

Цель MVP: быстро показать, как переводчик отправляет текст в Telegram и получает структурированный разбор перед переводом: повторы, термины-кандидаты, риски стиля/читабельности и управляемый черновик с учётом глоссария.

## Что открыть в первую очередь

- `docs/prototypes/final-mvp/index.html` — текущий bot-first MVP-прототип.
- `docs/prototypes/final-mvp/content/prante-content.json` — видимые тексты прототипа.
- `docs/prototypes/final-mvp/BOT_FLOW_CONTRACT.md` — соответствие экранов будущим действиям Telegram-бота.
- `docs/prototypes/project-2-task-3-mvp-spec.md` — постановка задачи MVP-прототипа.

## Почему код веб-страницы лежит в `docs/prototypes/`

Текущий HTML — это не production web app, а **демонстрационный прототип для командного ревью и сдачи задания**. Поэтому он хранится рядом с документацией, UX-контрактом, командным гайдом и постановкой задачи:

```text
docs/prototypes/final-mvp/
```

Эта структура намеренно фиксирует статус артефакта: это проверяемый MVP-макет Telegram-first сценария, а не финальная архитектура приложения. Если проект позже будет превращаться в полноценную веб-аппку или деплоиться как отдельный сайт, код можно вынести в `app/` или корневой static-site слой.

Локальный просмотр:

```bash
cd docs/prototypes/final-mvp
python3 -m http.server 8777
# открыть http://127.0.0.1:8777
```

## Базовые функции MVP

- Подсчёт повторений и частотных фрагментов в исходном тексте.
- Кандидаты в термины и рекомендации для глоссария.
- Контроль терминологической последовательности.
- Оценка рисков стиля и читабельности.
- Черновой перевод с учётом выбранных терминов.
- Сохранение терминов/правил в память только после подтверждения пользователя.

## Архитектурный принцип

```text
детерминированные tools + LLM для генерации/объяснения + память с подтверждением пользователя
```

Повторы, глоссарий, fuzzy matching, QA и diff считаются детерминированно. LLM используется для чернового перевода, объяснения правок и предложения правил, но не записывает активную память без подтверждения пользователя.

## Что не входит в публичный репозиторий

Локальные Telethon-сессии, Telegram-экспорты, временные архивы, verification screenshots, старые исходники и рабочие выгрузки игнорируются через `.gitignore`. Они могут оставаться на локальной машине, но не должны попадать в командный GitHub/zip.
