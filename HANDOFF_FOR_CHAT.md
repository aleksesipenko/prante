# ПРАНТЕ — сообщение для командного чата

Коллеги, собран bot-first MVP-прототип ПРАНТЕ.

Что смотреть:

- главный сценарий Telegram-бота: старт, загрузка/вставка текста, анализ, отчёт, глоссарий, черновик и подтверждение сохранения правила;
- поясняющие блоки ниже — только упаковка, основной артефакт именно bot-flow.

Локальный просмотр:

```bash
cd docs/prototypes/final-mvp
python3 serve_dev.py
# прототип: http://127.0.0.1:8777/docs/prototypes/final-mvp/index.html
# редакторский preview: http://127.0.0.1:8777/docs/prototypes/final-mvp/admin/
```

Что можно править:

- формулировки стартового сообщения;
- названия кнопок;
- текст отчёта;
- термины глоссария;
- текст черновика;
- пояснения для сдачи.

Как править:

- команда редактирует тексты в Google Sheets, не в коде;
- preview и проверка ошибок открываются по адресу `/docs/prototypes/final-mvp/admin/`;
- если таблица временно недоступна, сайт берёт fallback из `content/prante-content.json`;
- финальный snapshot в Git фиксируется через `python docs/prototypes/final-mvp/scripts/sync_google_sheet.py`.

Важно не ломать:

- бот должен оставаться главным макетом;
- память/правило сохраняется только после подтверждения пользователя;
- не добавляем лишние технические термины в пользовательский интерфейс;
- проверяющий должен понять сценарий за 30 секунд.
