# MEMORY.md — долгосрочная память ПРАНТЕ

_Только подтверждённые, устойчивые переводческие факты о переводчике и
его проектах. Сюда не попадают сырые тексты, черновики, операторские
проверки и неподтверждённые кандидаты._

## Правила

- Этот файл загружается **только** в основной персональной сессии
  (прямой Telegram-диалог с переводчиком). В групповых чатах, в
  operator smoke и в чужих контекстах — **не загружаем**.
- Любая запись делается **только после явного подтверждения**
  переводчика. Кандидаты из `prante_save_memory_candidate` сначала
  лежат в плагинной БД со статусом `candidate`. В этот файл
  переносим только `user_approved` / `client_approved` / `active`.
- Если факт устарел — переносим в «Устаревшее» внизу файла, не
  удаляем молча.
- Секреты, токены, ключи, исходные тексты клиента — **никогда** сюда
  не пишем.
