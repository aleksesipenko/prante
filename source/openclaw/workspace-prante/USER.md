# USER.md — профиль переводчика

_Минимальный профиль, который ПРАНТЕ заполняет в режиме онбординга
и дополняет по ходу работы. Не превращаем в досье: только то, что
помогает переводческой работе._

## Базовый профиль

- **Имя / как обращаться:** _(заполняется при онбординге)_
- **Telegram id:** _(используется только для allowlist в single-user
  MVP; хранится в OpenClaw config профиля `prante`, а не в этом
  файле и не в публичном git)_
- **Timezone / часы работы:** _(необязательно, удобно для cron и
  ночных тестов)_
- **Основная языковая пара:** _(например, `en → ru`)_
- **Дополнительные пары:** _(опционально)_

## Переводческие предпочтения

- **Основные домены / жанры:** _(например: UI/UX, юридический,
  маркетинг, инструкции)_
- **Стиль по умолчанию:** _(нейтральный, формальный, разговорный,
  технический)_
- **Обращение к читателю:** _(ты / вы / безлично)_
- **Формальность:** _(«сохранять формальность исходника» / «адаптировать
  под русский»)_
- **Глоссарий по умолчанию:** _(всегда использовать подтверждённые
  термины / спрашивать подтверждение)_
- **Сохранение правил:** _(сохранять только по явному «сохрани» /
  предлагать активные правила после серии подтверждений)_

## Что НЕ хранить

- **Operator smoke-сообщения** («проверь RAG», «ничего не записывай»)
  не попадают сюда.
- **Случайные правки в чужих проектах** не становятся глобальными
  правилами.
- **Сырые исходные тексты клиента** не сохраняем в профиле — только в
  контексте конкретной задачи.
- **Токены, ключи, конфиги** — никогда.

## Контекст

_(Что переводчик ценит в ассистенте, какие жанры ему нравятся, что
бесит, что рассмешит. Накапливается постепенно. Не собираем ради
досье — собираем ради лучшей работы.)_

---

Профиль — это рабочий контакт, а не паспорт. Уважай разницу.
