# ПРАНТЕ — короткий гайд для команды

## Что смотреть

Главный артефакт — сценарий Telegram-бота, а не лендинг.

Локально открыть прототип можно так:

```bash
cd docs/prototypes/final-mvp
python3 -m http.server 8777
# затем открыть http://127.0.0.1:8777
```

В прототипе нужно пройти сценарий: старт, загрузка/вставка текста, ход разбора, отчёт, глоссарий, черновик и подтверждение сохранения правила.

## Как править текст

Основной текст вынесен в:

```text
docs/prototypes/final-mvp/content/prante-content.json
```

Там можно править:

- стартовое сообщение бота;
- команды и кнопки;
- текст пользователя;
- шаги разбора;
- отчёт;
- термины глоссария;
- текст черновика;
- сообщение про сохранение правила;
- поясняющие блоки для сдачи.

## Что важно не менять без согласования

- Бот должен оставаться главным макетом.
- Сайт/лендинг не должен заменять bot-flow.
- Память сохраняется только после подтверждения пользователя.
- Не добавляйте технические термины в пользовательский интерфейс.
- Не перегружайте текст: проверяющий должен понять сценарий за 30 секунд.

## Как участвовать

1. Посмотреть прототип.
2. Выписать, какие фразы хочется заменить.
3. Внести правки в JSON или передать их ответственному за прототип.
4. После согласования финальная версия может быть задеплоена или превращена в короткое видео/гифку для сдачи.

## Как будут проверяться правки

1. Команда меняет только текстовые поля или явно согласованные UI-части.
2. Проверяется, что сценарий не сломан и текст не противоречит документам проекта.
3. После согласования фиксируется версия для сдачи.
