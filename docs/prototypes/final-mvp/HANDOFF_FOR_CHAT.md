# ПРАНТЕ — сообщение для командного чата

Коллеги, собран bot-first MVP-прототип ПРАНТЕ.

Что смотреть:

- главный сценарий Telegram-бота: старт, загрузка/вставка текста, анализ, отчёт, глоссарий, черновик и подтверждение сохранения правила;
- поясняющие блоки ниже — только упаковка, основной артефакт именно bot-flow.

Локальный просмотр:

```bash
cd docs/prototypes/final-mvp
python3 -m http.server 8777
# открыть http://127.0.0.1:8777
```

Что можно править:

- формулировки стартового сообщения;
- названия кнопок;
- текст отчёта;
- термины глоссария;
- текст черновика;
- пояснения для сдачи.

Важно не ломать:

- бот должен оставаться главным макетом;
- память/правило сохраняется только после подтверждения пользователя;
- не добавляем лишние технические термины в пользовательский интерфейс;
- проверяющий должен понять сценарий за 30 секунд.
